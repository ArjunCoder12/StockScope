# StockScope - AI-Powered Stock Analysis Dashboard

A comprehensive stock analysis platform that combines real-time market data, technical indicators, sentiment analysis, and AI-generated investment summaries.
## My Contributions — Spring 2026

**Arjun Ravishankar | ML & Algorithms Analyst, Momentum at Purdue**

My work focused on analyzing how relationships between stocks change across market conditions:

- Implemented a two-state Hidden Markov Model using VIX data to identify calmer (“Sunny”) and higher-volatility (“Raining”) market regimes.
- Developed separate lead–lag outputs for each regime.
- Added the `MLPropagationEdge` data model and the `hmmlearn` dependency to support this work.

This section describes my Spring 2026 contributions. The team continued development afterward; these implementations have not been located in this repository's current code or available history.

StockScope is a collaborative Purdue Momentum project. This portfolio copy is published with permission and retains the original commit history and team attribution.
