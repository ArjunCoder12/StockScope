# StockScope — New Member Onboarding Guide

Welcome to the team! This guide is designed to catch you up on the current progress of **StockScope** (and our V2 engine, **Uptick**) and outline how you will contribute to our upcoming milestones.

---

## 🚀 Project Vision
StockScope is an AI-powered stock analysis dashboard that bridge the gap between raw market data and actionable intelligence. We combine:
- **Real-time Market Data**: Price action, technical indicators, and fundamentals.
- **NLP Sentiment**: Using **FinBERT** to transform news headlines into directional signals.
- **AI Insights**: Leveraging **Gemini** to provide human-readable summaries for complex market movements.

---

## 📈 Current Progress & Victories

### 1. Sentiment Accuracy Milestone
On November 12, 2025, our FinBERT-based sentiment pipeline achieved **100% directional accuracy** across 1, 3, and 5-day horizons for our primary test tickers:
- **Predicted UP**: MRK (+2.75% over 5 days)
- **Predicted DOWN**: AAPL, TSLA, TTWO (Avg -3.01% over 5 days)

### 2. Infrastructure Expansion
We are currently transitioning from a JSON-based flat-file system to a robust dual-database architecture:
- **PostgreSQL**: For persistent data (Watchlists, Sentiment/Summary Cache, News).
- **Redis**: For high-speed caching of Alpha Vantage/yfinance data to respect API rate limits.

---

## 🛠 Project "Uptick" (V2 Engine)
We are currently in the middle of a high-intensity sprint to upgrade our core engine. This phase is internally code-named **Uptick**. Key components include:
- **NetworkX Pruning**: Removing "false positive" market signals using directed graph algorithms.
- **HMM Regime Detection**: Using Hidden Markov Models to detect market shifts.
- **Transfer Entropy**: Quantifying the flow of information between stocks.

## 🗺 Your Integration: The New Tracks
We have identified four key areas where your expertise is needed immediately:

### Track 1: UI/UX & Data Visualization
- **Goal**: Transform the React dashboard into a professional-grade trading tool.
- **Primary Tech**: React, Plotly.js, D3.js.
- **First Task**: Implement the "Regime Shift" visualization on the ticker charts.

### Track 2: Quality Assurance & Automated Testing
- **Goal**: Ensure the 100% accuracy milestone isn't a fluke.
- **First Task**: Build an automated backtesting suite that compares FinBERT sentiment against historical returns.

### Track 3: DevOps & Deployment
- **Goal**: Move from local development to a production-ready environment.
- **Primary Tech**: Docker, GitHub Actions, PostgreSQL RDS management.
- **First Task**: Containerize the `main.py` orchestrator and its worker dependencies.

### Track 4: Feature Expansion (Data Engineering)
- **Goal**: Add new data sources and improve our signal breadth.
- **First Task**: Expand the PostgreSQL schema to support "Sector Beta" and "Market Beta" metrics being generated by the Uptick engine.

## 🛠 Setup Instructions
1. **Clone the Repo**: `git clone ...`
2. **Environment**: Create a virtualenv and run `pip install -r requirements.txt`.
3. **Frontend**: Navigate to `/frontend` and run `npm install && npm start`.
4. **Environment Variables**: Copy `.env.example` to `.env` and add your keys for Alpha Vantage, Finnhub, and Gemini.
